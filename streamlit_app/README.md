# EXTRACTOR Web App

Estrattore automatico dati da visure catastali PDF dell'Agenzia delle Entrate.

## Funzionalità

- ✅ Upload multipli PDF (anche 50+ contemporaneamente)
- ✅ Estrazione automatica: Foglio, Numero, Sub, Categoria, Consistenza, Superficie, Rendita, Indirizzo
- ✅ Supporto formati moderni e legacy
- ✅ Filtri interattivi
- ✅ Download CSV
- ✅ Statistiche in tempo reale

# Installa dipendenze
